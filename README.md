# Bill Calculator

A simple Python program to calculate final bill amounts after applying discount and GST.

## Author

Ritik Ranjan Sahoo

## Features

- Accepts product price
- Applies discount percentage
- Adds GST
- Displays final bill amount

## Technologies Used

- Python

## Folder Structure

bill-calculator/
│── calculator.py
│── README.md

## How to Run

Run the program:

python calculator.py

## Example

Enter product price: 1000
Enter discount percentage: 10
Enter GST percentage: 18

Final Bill Amount: ₹1062.00

## Formula Used

Final Amount = (Price - Discount) + GST
